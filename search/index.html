Search

Search the scores of The 1520s Project for sequences of pitches, intervals, or note durations. Narrow the search by composer, genre, or number of voices. Each result links to the score and lists the measures in which the matches occur.

Search syntax
  • Use letter names for pitches, with # for sharp and b for flat, as in c# d eb.
  • Use interval numbers and add + or - for direction, as in +3 -2.
  • Use 0, 1, 2, 4, and 8 for a breve, semibreve, minim, semiminim, and fusa. Add a dot for a dotted duration.
  • Fill in multiple fields to match them at the same location. Use AND between patterns to find works containing each pattern, possibly in different movements.
